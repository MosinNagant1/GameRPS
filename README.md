Игра "Камень, ножницы, бумага"


Возможности

- Игра с ботом противником
- Ведёт счёт побед и поражений
- Обрабатывает ошибки, не даёт ввести лишние символы


Как запустить

1. Убедитесь что установлен Python 3 
2. Скачать файл GameRPS.py
3. Запустить в терминале


Пример работы 

Добро пожаловать в игру камень, ножницы, бумага!
Чтобы выбрать камень напишите К
Чтобы выбрать ножницы напишите Н
Чтобы выбрать бумагу напишите Б
Ваш ход: Н
